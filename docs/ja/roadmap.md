# ロードマップ

QvReader の開発計画、達成されたマイルストーン、および意図的に除外している機能について透明に公開します。
起動速度、バイナリサイズ、Markdown の忠実性、またはコアとなる閲覧体験を損なわないことが証明された機能のみが開発されます。

---

## 達成されたマイルストーン（v0.1.0 〜 v0.1.4）

- [x] **圧倒的なネイティブ性能と極小パッケージ（v0.1.4）**：約 5MB のネイティブバイナリ、614KB の JS エントリバンドル、100% WOFF2 数式フォント、50ms 未満のコールド起動、50,000 行以上の文書での 60 FPS 滑らかなスクロール。
- [x] **画面適応型フルードレイアウトエンジン（v0.1.3）**：ワイド画面での無駄な余白を削減する動的幅制御（896px〜1280px）、「適応 / 標準 / 全幅」の 3 モード切り替え。
- [x] **Mermaid 全画面拡大モーダル（v0.1.3）**：フローチャート、シーケンス図、アーキテクチャ図の描画、ダブルクリックによるパン・ドラッグ・拡大が可能な全画面モーダル。
- [x] **4 つの全シーン出力パイプライン（v0.1.3）**：インク節約印刷、高品位ベクター PDF、2x Retina 高解像度画像（クリップボード自動コピー）、完全自己完結型オフライン HTML。
- [x] **最小限の直感的インタラクション（v0.1.0）**：`.md` ダブルクリックでの即時閲覧、`Esc` での終了、`F2` でのインライン編集、`F3` でのリアルタイム分割プレビュー。
- [x] **バイトレベルの完全性と安全な保存（v0.1.0）**：LF/CRLF 改行と UTF-8 文字コードの厳格な保持、外部変更の衝突検知、未保存変更の保護。
- [x] **6 言語の完全サポート（v0.1.0 〜 v0.1.3）**：日本語、英語、簡体字中国語、韓国語、スペイン語、ポルトガル語（ブラジル）の 100% 対称性。

---

## 今後の候補（v0.1.5 以降）

- 🔄 **コード署名と公証の統合**：Apple Developer ID 署名および公証（Gatekeeper 警告の完全解消）と Windows SignPath オープンソースコード署名の適用。
- 🔄 **自動更新通知**：起動時に GitHub Releases を静かにチェックし、最新版がある場合に更新内容と通知を案内。
- 🔄 **コードブロック表示の向上**：行番号表示の切り替え、ワンクリックコピーのアニメーションフィードバック、長大コードブロックの折りたたみ。
- 🔄 **Linux パッケージの拡充**：Flatpak および Snap パッケージの公式配布整備。

---

## 意図的に除外された機能

- 強制的なクラウド同期やリモート Git 連携（ローカルファーストを厳守）。
- 月額定額制サブスクリプション（買い切り制を維持）。
- ブログ投稿や CMS 連携。
- 肥大化した IDE やナレッジグラフ機能。
- 閲覧を妨げる広告や邪魔なバッジ。

機能提案や議論は [GitHub Issues](https://github.com/qvcloud/QvReader/issues) で受け付けています。
