# 使い方とキーボードショートカット

QvReader は 3 つの状態を中心に設計されています。常に**読書モード**（デフォルト）から始まります。
これは唯一の安全なビューです——通常のクリックや入力がソースを変更することはありません。

## 基本操作

| 操作 | macOS | Windows / Linux |
|---|---|---|
| ファイルを開く | `.md` をダブルクリック、`qvreader file.md`、または ファイル → 開く | 同様 |
| フォルダをワークスペースとして開く | `qvreader .` | 同様 |
| **分割ビュー**に入る | `F3` | `F3` |
| **インライン編集**に入る | `F2` | `F2` |
| 読書に戻る | `F3` / `F2`（トグル） | 同様 |
| 保存 | `Cmd + S` | `Ctrl + S` |
| ズーム | `Cmd + スクロール` | `Ctrl + スクロール` |
| 閉じる / 終了 | `Esc`（クリーン時） | `Esc` |
| 設定 | `Cmd + ,` | `Ctrl + ,` |

## 読書モード

- 読み、スクロールし、テキストを選択し、リンクを辿り、画像を見る。
- **アウトライン**サイドバー：見出しでナビゲート、現在のセクションを強調。
- **ワークスペース**サイドバー：フォルダ内の Markdown ファイルを閲覧・切り替え。
- **テーマ**と文字サイズは設定（`Cmd/Ctrl+,`）にあります。

## 分割ビュー（F3）

- 左：Markdown ソース。右：ライブレンダリングプレビュー。
- 編集するとプレビューが更新されます（デバウンスされ、入力は滑らかなまま）。
- スクロールしたペインがもう片方を駆動し、**アクティブ行はプレビューでハイライト**され、揃います。
- `Cmd/Ctrl+S` で保存。元の改行とエンコーディングは保持されます。

## インライン編集（F2）

- 読書キャンバス上の現在位置で直接編集。
- ちょっとしたタイプミスや壊れたリンク、分割ペインを開かずに 1 行直したいときに便利。
- 分割ビューと同じソース忠実度ルール。

## 保存と安全性

- QvReader はファイルの**元のバイト**を保持します：改行（LF/CRLF）と
  エンコーディング（UTF-8、BOM あり/なし）を検出し、そのまま書き戻します。
- QvReader の外でファイルがディスク上で変更された場合、上書き前に警告します。
- 未保存の編集がある状態で閉じる・モード切替すると、保存・破棄・留まるを尋ねます。

## 言語

設定 → 一般 → 言語 で UI 言語を切り替えられます。対応：English、简体中文、
日本語、한국어、Português (Brasil)、Español。
