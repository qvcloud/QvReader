# 使い方とキーボードショートカット

QvReader は 3 つの状態を中心に設計されています。常に最も安全な**閲覧モード**（クリックやキー入力で原ファイルが破壊されない安全な状態）から始まります。

## 主要ショートカット一覧

| 操作 / モード | macOS | Windows / Linux | 説明 |
|---|---|---|---|
| ファイルを開く | `.md` ダブルクリック、または `qvreader file.md` | 同左 | 瞬時のコールド起動 |
| フォルダをワークスペースとして開く | `qvreader .` | 同左 | フォルダドロワーを読み込み |
| **インライン編集** | `F2` | `F2` | 原位置編集、**永久 100% 無料** |
| **分割プレビュー** | `F3` | `F3` | 左右並行編集；300 回試用、上限後も非ロック |
| 閲覧に戻る / 編集終了 | `Esc` または再度 `F2`/`F3` | 同左 | クリーンな閲覧画面へ復帰 |
| ドキュメント保存 | `Cmd + S` | `Ctrl + S` | LF/CRLF 改行と UTF-8 符号を完全保持 |
| 印刷 | `Cmd + P` | `Ctrl + P` | ネイティブ印刷ダイアログと省インクスタイル |
| PDF 出力 | `Cmd + Shift + P` | `Ctrl + Shift + P` | ベクター PDF 直接生成 |
| Retina 画像出力 | `Cmd + Shift + E` | `Ctrl + Shift + E` | 2x Retina 画像出力とクリップボード自動コピー |
| 独立 HTML 出力 | `Cmd + Shift + H` | `Ctrl + Shift + H` | 完全独立オフライン HTML バンドル |
| 目次（TOC）サイドバー切り替え | `Cmd + Shift + O` | `Ctrl + Shift + O` | 見出しレベルで文書内を移動 |
| ワークスペースサイドバー切り替え | `Cmd + Shift + W` | `Ctrl + Shift + W` | プロジェクト内のファイルツリーを表示 |
| ショートカット一覧表示 | `Cmd + /` | `Ctrl + /` | クイックヘルプ表示 |
| ズーム倍率変更 | `Cmd + ホイール` | `Ctrl + ホイール` | 文字および画面全体の拡大縮小 |
| ウィンドウを閉じる / 終了 | `Esc`（未変更時） | `Esc` | 瞬時に終了 |
| 設定センター | `Cmd + ,` | `Ctrl + ,` | テーマ、排版モード、フォント調整 |

---

## 閲覧モード

- **安全な閲覧**：スクロール、テキスト選択、リンク遷移、画像表示。
- **画面適応型レイアウト**：適応型（896px〜1280px）、標準（896px 固定）、全幅の 3 モードを設定（`Cmd/Ctrl+,`）から即座に変更可能。
- **Mermaid 図表の操作**：図表をダブルクリックすると全画面モーダルが開き、ドラッグ移動やマウスホイールでの拡大縮小が可能。
- **目次ナビゲーション**：サイドバー（`Cmd/Ctrl+Shift+O`）で現在読んでいる章をハイライト。
- **標準印刷**：`Cmd/Ctrl+P` で余白が最適化された印刷ダイアログを起動。

---

## インライン編集（F2）

- **中核機能、永久無料**：試用制限なし、ポップアップなし。
- 閲覧画面上の現在のカーソル位置でそのまま直接編集を開始。
- 誤字修正や軽微な追記に最適。完了後 `Esc` または `F2` でシームレスに閲覧画面へ復帰。
- `Cmd/Ctrl+S` で保存。元の改行コードとエンコーディングを厳格に保持。

---

## 分割ビュー（F3）

- 左側に Markdown ソースエディター、右側にリアルタイムプレビュー。
- 入力に合わせてプレビューがリアルタイムに更新（スマートデバウンス内蔵）。
- 左右のスクロールが連動し、**アクティブな行がプレビュー側でハイライト表示**。
- **試用ポリシー**：300 回の試用が可能。**上限に達しても機能はロックされず継続して使用可能**（新規ファイルを開く際に緩やかな案内が出るのみ）、**保存と編集は絶対にブロックされません**。

---

## ワークスペースと高度な出力（Pro 機能）

- **ワークスペースドロワー**（`Cmd/Ctrl+Shift+W`）：フォルダ内の全 Markdown ファイルをツリー形式で管理。
- **高度な出力パイプライン**：ベクター PDF（`Cmd/Ctrl+Shift+P`）、2x Retina 画像（`Cmd/Ctrl+Shift+E`）、独立 HTML（`Cmd/Ctrl+Shift+H`）。
- コミュニティ版には 300 回の体験枠が付属；Pro 版は無制限。

---

## セキュリティと信頼手順

- **macOS**：開発元警告が表示された場合は、アプリを右クリックして「開く」を選択するか、ターミナルで `xattr -cr /Applications/QvReader.app` を実行してください。
- **Windows**：SmartScreen 警告が表示された場合は、「詳細情報」をクリックして「実行」を選択してください。
