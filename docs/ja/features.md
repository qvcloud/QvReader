# 機能特性

QvReader が現在実現していること、および意図的に除外している設計方針について説明します。

## 製品の理念

QvReader は、過不足のない編集機能を備えた**超軽量・高速・文書本位の Markdown リーダー**です。
README、AI 生成ドキュメント、ローカル仕様書などを「Web ページのように快適に開き、必要に応じて微修正し、`Esc` で閉じる」という日常的なユースケースに特化しています。IDE、複雑なナレッジグラフ、クラウド同期データベース、重厚な CMS ではありません。

基本原則（プロジェクト憲章より）：

1. 高速起動と極小パッケージ（~5MB、コールド起動 <50ms）。
2. 広告やノイズのないクリーンな閲覧画面。
3. 閲覧がデフォルト；編集は明示的な操作であり、誤編集を防止。
4. 編集は日常的な修正に十分でありながら、決して肥大化させない。
5. ローカルファイル重視、アカウント登録不要、プライバシー 100% 保護。

## エディションと機能マトリクス

### コミュニティ版（Community Edition - 永久無料）

- **即時高速閲覧**：CommonMark / GFM 完全準拠、コールド起動 50ms 未満、省メモリ。50,000 行以上の長大文書も 60 FPS で快適スクロール。
- **画面適応型フルードレイアウト**：896px〜1280px の動的幅制御。設定で「適応（adaptive）/ 標準（standard）/ 全幅（full）」を切り替え可能。
- **バイトレベルの完全性**：原ファイルが唯一の真実。改行コード（LF/CRLF）や文字コード（UTF-8/BOM）を忠実に保持。
- **F2 インライン編集（中核機能、永久無料）**：CodeMirror 6 採用、閲覧キャンバス上で直接編集可能。制限やポップアップなし。
- **F3 リアルタイム分割プレビュー**：左側にソース、右側にミリ秒同期プレビュー。300 回の試用枠付き；**上限到達後もロックされず継続利用可能**（新規ファイル時に緩やかな案内が表示されるのみ）、**保存と編集は絶対にブロックされません**。
- **図表と数式**：Mermaid ネイティブ図表描画および KaTeX 数式描画。**Mermaid 図表のダブルクリックによる全画面拡大モーダル**（ドラッグ・パン・ズーム対応）をサポート。
- **ナビゲーション**：見出し目次（TOC）、右クリックメニュー、テーマ切り替え、フォントサイズ変更。
- **ネイティブ印刷**：`Cmd/Ctrl+P` でシステム印刷を即座に起動、インク節約レイアウト適用。
- **CLI 起動**：ターミナルから直接起動可能（`qvreader <ファイル>` / `qvreader .`）。
- **6 言語対応**：日本語、英語、簡体字中国語、韓国語、スペイン語、ポルトガル語（ブラジル）を内蔵。

### Pro 版（Pro Edition - $9.99 買い切り）

- **十分な無料体験**：コミュニティ版に 300 回の Pro 機能体験枠が付属。
- **ワークスペース管理**：フォルダドロワーとツリー構造（`Cmd/Ctrl+Shift+W`）で複数ファイルを軽快に管理。
- **多彩な出力パイプライン**：
  - **ベクター PDF 出力**（`Cmd/Ctrl+Shift+P`）：レイアウト崩れのない直接 PDF 生成。
  - **Retina 長図 PNG 出力**（`Cmd/Ctrl+Shift+E`）：2x Retina 高解像度キャプチャ、クリップボード自動同期。
  - **独立 HTML 出力**（`Cmd/Ctrl+Shift+H`）：完全自己完結型オフライン HTML ファイル生成。
- **100% オフライン認証**：生涯アップデート付き買い切り、個人デバイス 3 台以上対応、Pro 案内の完全消去。

## プラットフォーム対応

| プラットフォーム | ステータス | 配布パッケージ |
|---|---|---|
| macOS（Apple Silicon / arm64） | 主要対応 | `QvReader-0.1.4-arm64.dmg` |
| macOS（Intel / x64） | 主要対応 | `QvReader-0.1.4-x64.dmg` |
| Windows（x64） | CI によるサポート | `QvReader-0.1.4-x64-setup.exe` / `.zip` |
| Linux（Debian / AppImage） | 安定化後に評価 | `QvReader-0.1.4-amd64.AppImage` |

---

## 意図的に除外された機能

- 強制的なクラウド同期やアカウント登録。
- 月額課金・定額サブスクリプション。
- ブログ投稿や CMS 連携。
- 重厚な IDE やナレッジグラフ。
- 閲覧を妨げる広告や邪魔なバッジ。

ロードマップの詳細は [roadmap.md](roadmap.md) をご覧ください。
