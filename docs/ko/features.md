# 기능

QvReader가 오늘 무엇을 하는지, 그리고 의도적으로 하지 않는 것을 간결하고 정직하게 설명합니다.

## 제품 포지션

QvReader는 **가볍고, 빠르고, 문서 중심의 Markdown 리더**로, 딱 충분한 편집 기능을 갖췄습니다.
"README / AI 생성 문서 / 로컬 메모를 빠르게 읽기" 순간을 겨냥합니다 — 열고, 웹페이지처럼 읽고,
필요하면 그 자리에서 편집하고, `Esc`로 닫습니다. **IDE**도, 지식 베이스도, 클라우드 동기화 볼트도,
완전한 CMS도 아닙니다.

핵심 가치(프로젝트 헌장에서):

1. 여는 게 빠르고, 설치가 작습니다.
2. 깔끔한 읽기 화면, 군더더기 없음.
3. 읽기가 기본이며, 편집은 명시적이라 소스를 실수로 바꿀 수 없습니다.
4. 편집은 실제 수정에 충분한 정도이며, 무거운 에디터가 되지 않습니다.
5. 로컬 파일, 로컬 우선, 필수 계정이나 클라우드 없음.

## 현재 기능 (v0.1.0)

- CommonMark / GFM 문서 **즉시 읽기**.
- **충실성** — 소스 파일이 유일한 진실. 알 수 없는 구문·줄 바꿈·인코딩을 그대로 보존.
- 라이브 미리보기가 있는 **F2 인라인 편집** 및 **F3 분할 편집**.
- **코드 강조**(highlight.js), **수식**(KaTeX).
- **TOC 개요**, 파일 트리가 있는 **폴더 워크스페이스**.
- **테마**, 조절 가능한 글자 크기, **6개 UI 언어**.
- **CLI**(`qvreader <파일>` / `qvreader .`).

## 크로스 플랫폼

| 플랫폼 | 상태 |
|---|---|
| macOS (Apple Silicon + Intel, universal) | 주요, 지원 |
| Windows (x64) | CI를 통해 지원 |
| Linux (Debian / AppImage) | 핵심 안정화 후 평가 |

## 명시적으로 범위 제외

프로젝트 헌장은 "빠르고, 작고, 집중된" 정체성을 지키기 위해 다음을 제외합니다:

- 클라우드 동기화, Git 호스팅 동기화, 내장 드라이브.
- 블로그 게시, WeChat 기사 레이아웃, 범용 CMS.
- Typora, Obsidian, VS Code에 맞추는 지식 베이스 / IDE.
- 계정, 결제, 활성화 코드, 구독, 다중 기기 라이선스.
- 기본 파일 연결의 강제 또는 조용한 설정.
- 방대하고 검증되지 않은 플러그인 및 테마 생태계.
