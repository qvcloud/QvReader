# 기능 상세

QvReader가 현재 지원하는 기능과 의도적으로 배제한 설계 철학에 대한 명확한 안내입니다.

## 제품 철학

QvReader는 필요한 만큼의 편집 기능을 갖춘 **초경량, 고속, 문서 중심의 Markdown 뷰어**입니다.
README, AI 생성 문서, 로컬 기술 사양서를 웹 페이지처럼 빠르고 편안하게 열어보고, 필요할 때 제자리에서 수정하며, `Esc`로 즉시 닫는 일상적인 시나리오에 특화되어 있습니다. 복잡한 IDE, 방대한 지식 그래프, 클라우드 데이터베이스가 아닙니다.

핵심 가치 (프로젝트 헌법 발췌):

1. 빠른 실행 속도와 약 5MB의 초소형 바이너리 (50ms 미만 콜드 스타트).
2. 광고나 산만함이 없는 깔끔한 문서 중심 화면.
3. 읽기 모드가 기본이며, 편집은 명시적으로 수행되어 원본 파괴 방지.
4. 일상적인 수정에 충분하지만 절대 무거운 편집기가 되지 않음.
5. 로컬 파일 우선, 계정 가입 불필요, 완벽한 프라이버시 보호.

## 에디션 및 기능 매트릭스

### 커뮤니티 에디션 (Community Edition - 평생 무료)

- **즉각적인 고성능 읽기**: CommonMark / GFM 완벽 지원, 50ms 미만 시작, 극소 메모리 사용. 50,000행 이상의 대용량 문서도 60 FPS 부드러운 스크롤.
- **화면 맞춤형 유동 레이아웃**: 896px~1280px 동적 폭 제어. 설정에서 '적응형 / 표준 / 전체 폭' 3가지 모드 선택 지원.
- **원본 바이트 보존**: 소스 파일이 유일한 기준입니다. 줄바꿈(LF/CRLF) 및 인코딩(UTF-8/BOM)을 손실 없이 보존.
- **F2 인라인 편집 (핵심 기능, 영구 무료)**: CodeMirror 6 기반, 읽기 화면에서 제자리 즉시 편집. 제한 및 팝업 없음.
- **F3 실시간 분할 미리보기**: 좌측 소스, 우측 밀리초 실시간 미리보기. 300회 체험 제공; **체험 소진 후에도 절대 잠기지 않고 계속 사용 가능** (새 파일 전환 시 완만한 Pro 안내만 표시), **문서 편집 및 저장은 결코 차단되지 않음**.
- **다이어그램 및 수식**: Mermaid 네이티브 렌더링 및 KaTeX 수식 지원. **Mermaid 다이어그램 더블 클릭 시 드래그 및 확대가 가능한 전체화면 인터랙티브 모달** 지원.
- **문서 탐색**: 목차 사이드바(TOC), 우클릭 메뉴, 테마 전환, 글꼴 크기 조절.
- **네이티브 시스템 인쇄**: `Cmd/Ctrl+P`로 잉크 절약 스타일의 인쇄 대화상자 호출.
- **터미널 CLI 지원**: 터미널에서 즉시 실행 가능 (`qvreader <파일>` / `qvreader .`).
- **6개 국어 지원**: 한국어, 영어, 중국어(간체), 일본어, 스페인어, 포르투갈어(브라질) 지원.

### 프로 에디션 (Pro Edition - $9.99 영구 라이선스)

- **충분한 무료 체험**: 커뮤니티 에디션에 300회의 Pro 기능 평가 기회 기본 포함.
- **워크스페이스 관리**: 폴더 서랍 및 트리 구조(`Cmd/Ctrl+Shift+W`)로 프로젝트 내 다중 문서 탐색.
- **전방위 내보내기 파이프라인**:
  - **벡터 PDF 내보내기** (`Cmd/Ctrl+Shift+P`): 고품질 벡터 PDF 생성.
  - **2x Retina PNG 이미지 내보내기** (`Cmd/Ctrl+Shift+E`): 고해상도 캡처 및 클립보드 자동 복사.
  - **독립형 HTML 내보내기** (`Cmd/Ctrl+Shift+H`): 오프라인 자급형 단일 HTML 파일 생성.
- **100% 로컬 오프라인 인증**: 평생 업데이트 포함 1회 구매, 3대 이상 디바이스 지원, Pro 안내 메시지 완전 제거.
