# 사용 가이드 및 단축키

QvReader는 세 가지 핵심 상태를 기반으로 설계되었습니다. 항상 가장 안전한 **읽기 모드**에서 시작합니다 (일반적인 클릭과 입력으로 원본 파일이 손상되지 않는 안전한 환경).

## 핵심 단축키 안내

| 작업 / 모드 | macOS | Windows / Linux | 설명 |
|---|---|---|---|
| 파일 열기 | `.md` 더블 클릭, 또는 `qvreader file.md` | 동일 | 밀리초 즉각 실행 |
| 폴더를 워크스페이스로 열기 | `qvreader .` | 동일 | 폴더 서랍 사이드바 로드 |
| **인라인 편집** | `F2` | `F2` | 읽기 화면 제자리 즉시 편집, **영구 100% 무료** |
| **분할 미리보기** | `F3` | `F3` | 좌우 실시간 동기화 편집; 300회 체험, 소진 후 미잠금 |
| 읽기로 복귀 / 편집 종료 | `Esc` 또는 `F2`/`F3` 재입력 | 동일 | 깔끔한 읽기 화면 복귀 |
| 문서 저장 | `Cmd + S` | `Ctrl + S` | LF/CRLF 줄바꿈 및 UTF-8 인코딩 보존 |
| 시스템 인쇄 | `Cmd + P` | `Ctrl + P` | 잉크 절약 스타일의 인쇄 대화상자 |
| PDF 내보내기 | `Cmd + Shift + P` | `Ctrl + Shift + P` | 벡터 PDF 직접 생성 |
| Retina 이미지 내보내기 | `Cmd + Shift + E` | `Ctrl + Shift + E` | 2x Retina 이미지 및 클립보드 자동 복사 |
| 독립 HTML 내보내기 | `Cmd + Shift + H` | `Ctrl + Shift + H` | 오프라인 자급형 단일 HTML 파일 |
| 목차 사이드바 전환 | `Cmd + Shift + O` | `Ctrl + Shift + O` | 헤딩 수준별 문서 탐색 |
| 워크스페이스 사이드바 전환 | `Cmd + Shift + W` | `Ctrl + Shift + W` | 다중 문서 프로젝트 트리 탐색 |
| 단축키 안내창 | `Cmd + /` | `Ctrl + /` | 빠른 단축키 팝업 |
| 확대/축소 | `Cmd + 휠` | `Ctrl + 휠` | 글꼴 및 인터페이스 배율 조절 |
| 창 닫기 / 종료 | `Esc` (미변경 시) | `Esc` | 즉각 닫기 |
| 설정 센터 | `Cmd + ,` | `Ctrl + ,` | 테마, 레이아웃 모드, 글꼴 설정 |

---

## 읽기 모드

- **안전한 읽기**: 스크롤, 텍스트 선택, 링크 클릭, 이미지 보기.
- **화면 맞춤형 레이아웃**: 적응형(896px~1280px), 표준(896px 고정), 전체 폭 3가지 모드를 설정(`Cmd/Ctrl+,`)에서 즉시 전환.
- **Mermaid 다이어그램 제어**: 다이어그램을 더블 클릭하여 전체화면 모달을 열고 드래그 이동 및 마우스 휠 확대/축소 가능.
- **목차 네비게이션**: 사이드바(`Cmd/Ctrl+Shift+O`)를 통해 현재 읽고 있는 단락 강조 표시.
- **표준 인쇄**: `Cmd/Ctrl+P`로 인쇄 최적화 스타일 적용.

---

## 인라인 편집 (F2)

- **핵심 기능, 영구 무료**: 체험 제한 없음, 팝업 없음.
- 읽기 화면의 현재 커서 위치에서 바로 편집을 시작하여 시각적 맥락 유지.
- 오타 수정이나 간단한 수정에 적합하며, 완료 후 `Esc` 또는 `F2`로 부드럽게 읽기 화면으로 복귀.
- `Cmd/Ctrl+S`로 저장하며, 원본 바이트 형식을 보존.

---

## 분할 뷰 (F3)

- 좌측 소스 편집기, 우측 실시간 미리보기.
- 입력 시 스마트 디바운스를 통해 지연 없이 미리보기가 즉각 갱신.
- 좌우 스크롤 연동 및 **활성 행 미리보기 하이라이트 동기화**.
- **체험 정책**: 300회의 무료 체험 제공. **한도 소진 후에도 기능이 잠기지 않고 지속 사용 가능** (새 파일을 열 때 완만한 Pro 안내만 표시), **문서 편집 및 저장은 결코 차단되지 않음**.

---

## 워크스페이스 및 고급 내보내기 (Pro 기능)

- **워크스페이스 서랍** (`Cmd/Ctrl+Shift+W`): 디렉터리 내의 모든 마크다운 파일 탐색.
- **고급 내보내기**: 벡터 PDF(`Cmd/Ctrl+Shift+P`), 2x Retina 이미지(`Cmd/Ctrl+Shift+E`), 단일 HTML(`Cmd/Ctrl+Shift+H`).
- 커뮤니티 에디션에 300회 체험 포함; Pro 버전은 무제한.

---

## 보안 신뢰 설정 안내

- **macOS**: 개발자 경고 발생 시 앱을 우클릭하여 '열기'를 선택하거나, 터미널에서 `xattr -cr /Applications/QvReader.app`을 실행하세요.
- **Windows**: SmartScreen 경고 시 '추가 정보' 클릭 후 '실행'을 선택하세요.
