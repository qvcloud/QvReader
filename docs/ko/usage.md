# 사용법 및 키보드 단축키

QvReader는 세 가지 상태를 중심으로 설계되었습니다. 항상 **읽기 모드**(기본값)에서 시작합니다.
일반적인 클릭과 입력이 소스를 절대 변경하지 않는 유일하고 안전한 보기입니다.

## 핵심 조작

| 동작 | macOS | Windows / Linux |
|---|---|---|
| 파일 열기 | `.md` 더블클릭, `qvreader file.md`, 또는 파일 → 열기 | 동일 |
| 폴더를 워크스페이스로 열기 | `qvreader .` | 동일 |
| **분할 보기** 진입 | `F3` | `F3` |
| **인라인 편집** 진입 | `F2` | `F2` |
| 읽기로 복귀 | `F3` / `F2`(토글) | 동일 |
| 저장 | `Cmd + S` | `Ctrl + S` |
| 확대/축소 | `Cmd + 스크롤` | `Ctrl + 스크롤` |
| 닫기 / 종료 | `Esc`(깨끗할 때) | `Esc` |
| 설정 | `Cmd + ,` | `Ctrl + ,` |

## 읽기 모드

- 읽고, 스크롤하고, 텍스트를 선택하고, 링크를 따라가고, 이미지를 봅니다.
- **개요** 사이드바: 제목으로 탐색, 현재 섹션 강조.
- **워크스페이스** 사이드바: 폴더 내 Markdown 파일을 탐색하고 전환.
- **테마** 및 글자 크기는 설정(`Cmd/Ctrl+,`)에 있습니다.

## 분할 보기 (F3)

- 왼쪽: Markdown 소스. 오른쪽: 라이브 렌더링 미리보기.
- 편집 시 미리보기가 업데이트됩니다(디바운스되어 입력이 매끄럽습니다).
- 스크롤한 창이 다른 쪽을 이끌고, **활성 줄이 미리보기에서 강조**되어 정렬됩니다.
- `Cmd/Ctrl+S`로 저장. 원래 줄 바꿈과 인코딩이 보존됩니다.

## 인라인 편집 (F2)

- 읽기 캔버스의 현재 위치에서 직접 편집.
- 빠른 오타 수정, 끊어진 링크, 분할 창 없이 한 줄 고치기에 적합.
- 분할 보기와 동일한 소스 충실도 규칙.

## 저장 및 안전

- QvReader는 파일의 **원본 바이트**를 보존합니다: 줄 바꿈(LF/CRLF)과 인코딩(UTF-8, BOM 포함/미포함)을
  감지해 그대로 다시 씁니다.
- QvReader 밖에서 파일이 디스크에서 변경되면 덮어쓰기 전에 경고합니다.
- 저장하지 않은 편집이 있는 채 닫거나 모드를 전환하면 저장·버리기·머물기를 묻습니다.

## 언어

설정 → 일반 → 언어에서 UI 언어를 전환합니다. 지원: English, 简体中文,
日本語, 한국어, Português (Brasil), Español.
