# 로드맵

QvReader가 계획 중인 방향, 완료된 마일스톤, 그리고 의도적으로 제외한 설계 경계를 투명하게 공유합니다.
실행 속도, 번들 크기, Markdown 보존성, 또는 핵심 읽기 경험을 해치지 않는 기능만 개발 대상으로 선정됩니다.

---

## 달성된 마일스톤 (v0.1.0 ~ v0.1.4)

- [x] **극한의 성능 및 번들 최적화 (v0.1.4)**: 약 5MB 네이티브 바이너리, 614KB JS 엔트리 번들, 100% WOFF2 수학 폰트, 50ms 미만 콜드 스타트, 50,000행 이상 문서 60 FPS 부드러운 스크롤.
- [x] **화면 맞춤형 유동 레이아웃 엔진 (v0.1.3)**: 와이드 모니터의 과도한 여백을 줄여주는 동적 폭 관리(896px~1280px), '적응형 / 표준 / 전체 폭' 3가지 모드 지원.
- [x] **Mermaid 전체화면 확대 모달 (v0.1.3)**: 플로우차트, 시퀀스, 아키텍처 다이어그램 지원, 더블 클릭 시 드래그 및 확대/축소가 가능한 전체화면 모달.
- [x] **4가지 전방위 내보내기 파이프라인 (v0.1.3)**: 잉크 절약 인쇄, 고품질 벡터 PDF, 클립보드 자동 복사가 포함된 2x Retina 이미지, 완전 독립 오프라인 HTML.
- [x] **미니멀 핵심 인터랙션 계약 (v0.1.0)**: `.md` 더블 클릭 즉각 읽기, `Esc` 닫기, `F2` 인라인 편집, `F3` 실시간 분할 미리보기.
- [x] **원본 바이트 보존 및 안전 저장 (v0.1.0)**: LF/CRLF 줄바꿈 및 UTF-8 인코딩 손실 없는 보존, 외부 변경 충돌 방지, 저장되지 않은 변경 보호.
- [x] **6개 국어 완벽 지원 (v0.1.0 ~ v0.1.3)**: 한국어, 영어, 중국어(간체), 일본어, 스페인어, 포르투갈어(브라질) 완전 대칭 지원.

---

## 향후 후보 과제 (v0.1.5 이상)

- 🔄 **코드 서명 및 공증 통합**: Apple Developer ID 서명 및 공증(Gatekeeper 경고 완전 해소)과 Windows SignPath 오픈소스 코드 서명 인증서 적용.
- 🔄 **자동 업데이트 알림**: 실행 시 조용하게 GitHub Releases를 확인하여 새 버전 출시 시 우아한 업데이트 안내 제공.
- 🔄 **코드 블록 향상**: 코드 줄 번호 표시 토글, 복사 피드백 애니메이션, 대형 코드 블록 접기 지원.
- 🔄 **Linux 패키징 생태계 확장**: 공식 Flatpak 및 Snap 패키지 배포 채널 구축.

---

## 의도적으로 제외된 기능

- 강제 클라우드 동기화나 원격 저장소 연동 (로컬 우선 원칙 엄수).
- 월간 정기 구독 모델 (평생 영구 라이선스 유지).
- 블로그 발행이나 웹 CMS 기능.
- 비대한 IDE 또는 무거운 지식 그래프.
- 읽기를 방해하는 침입형 광고.

기능 논의는 [GitHub Issues](https://github.com/qvcloud/QvReader/issues)에서 진행됩니다.
