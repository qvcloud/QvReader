# 用法与键盘快捷键

QvReader 围绕三种状态设计。你始终从**阅读模式**开始（默认状态，也是唯一安全的视图——
普通的点击与键入绝不会修改你的源文件）。

## 核心操作

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 打开文件 | 双击 `.md`，或 `qvreader file.md`，或 文件 → 打开 | 相同 |
| 将文件夹作为工作区打开 | `qvreader .` | 相同 |
| 进入**分屏视图** | `F3` | `F3` |
| 进入**就地编辑** | `F2` | `F2` |
| 返回阅读 | `F3` / `F2`（切换） | 相同 |
| 保存 | `Cmd + S` | `Ctrl + S` |
| 缩放 | `Cmd + 滚轮` | `Ctrl + 滚轮` |
| 关闭 / 退出 | `Esc`（文档干净时） | `Esc` |
| 设置 | `Cmd + ,` | `Ctrl + ,` |

## 阅读模式

- 阅读、滚动、选中文本、点击链接、查看图片。
- **大纲**侧栏：按标题导航；当前章节高亮。
- **工作区**侧栏：浏览并在文件夹内的 Markdown 文件间切换。
- **主题**与字号位于设置（`Cmd/Ctrl+,`）中。

## 分屏视图（F3）

- 左侧：Markdown 源码。右侧：实时渲染预览。
- 编辑会更新预览（做了防抖，输入依然流畅）。
- 滚动的窗格带动另一侧；你的**活动行在预览端高亮**并保持对齐。
- 使用 `Cmd/Ctrl+S` 保存。原始换行与编码被保留。

## 就地编辑（F2）

- 直接在阅读画布当前光标处编辑。
- 适合快速修正错别字、坏链接，或一处小改动而无需打开分屏。
- 与分屏视图相同的源保真规则。

## 保存与安全

- QvReader 保留你文件的**原始字节**：检测换行（LF/CRLF）与编码（UTF-8，含/不含 BOM），
  写回时原样保留。
- 如果文件在 QvReader 之外被磁盘上的其他程序修改，覆盖前会提醒你。
- 存在未保存修改时关闭或切换模式，会询问保存、放弃或停留。

## 语言

在 设置 → 通用 → 语言 中切换界面语言。支持：English、简体中文、
日本語、한국어、Português (Brasil)、Español。
