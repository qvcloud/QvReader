# 用法与键盘快捷键

QvReader 围绕三种状态设计。你始终从**阅读模式**开始（默认状态，也是唯一安全的视图——普通的点击与键入绝不会修改你的源文件）。

## 核心快捷键一览

| 操作 / 模式 | macOS | Windows / Linux | 说明 |
|---|---|---|---|
| 打开文件 | 双击 `.md`，或 `qvreader file.md` | 相同 | 毫秒级冷启打开阅读 |
| 将文件夹作为工作区打开 | `qvreader .` | 相同 | 加载工作区侧栏 |
| **就地编辑** | `F2` | `F2` | 阅读画布原位即时编辑，**永久 100% 免费** |
| **分屏实时预览** | `F3` | `F3` | 左源码右预览，300 次试用，超额不锁死 |
| 返回阅读 / 退出编辑 | `Esc` 或再按 `F2`/`F3` | 相同 | 退出编辑模式 |
| 保存文档 | `Cmd + S` | `Ctrl + S` | 严格保留原始 LF/CRLF 与 UTF-8 编码 |
| 标准打印 | `Cmd + P` | `Ctrl + P` | 原生系统打印对话框与墨水友好样式 |
| 导出为 PDF | `Cmd + Shift + P` | `Ctrl + Shift + P` | 高保真矢量 PDF 输出 |
| 导出为高清长图（PNG） | `Cmd + Shift + E` | `Ctrl + Shift + E` | 2x Retina 截图并自动复制到剪贴板 |
| 导出为独立 HTML | `Cmd + Shift + H` | `Ctrl + Shift + H` | 离线自包含便携式单文件 HTML |
| 切换大纲侧栏 | `Cmd + Shift + O` | `Ctrl + Shift + O` | 按标题级别导航长文档 |
| 切换工作区侧栏 | `Cmd + Shift + W` | `Ctrl + Shift + W` | 浏览多文档工程目录树 |
| 快捷键速查 | `Cmd + /` | `Ctrl + /` | 快速调出快捷键卡片 |
| 缩放比例 | `Cmd + 滚轮` | `Ctrl + 滚轮` | 界面与文本缩放 |
| 关闭窗口 / 退出 | `Esc`（文档未修改时） | `Esc` | 极速退出阅读 |
| 打开设置中心 | `Cmd + ,` | `Ctrl + ,` | 主题、排版模式、字号调节 |

## 阅读模式

- **默认安全**：阅读、滚动、选中文本、点击链接、查看图片。
- **智能屏宽排版**：支持自适应（896px~1280px 流式）、标准（896px 固定）与全宽 3 种排版，在设置中心（`Cmd/Ctrl+,`）中即时生效。
- **Mermaid 图表交互**：双击任意 Mermaid 流程图或时序图，即可弹出全屏交互式缩放弹窗，支持自由拖拽平移与滚轮缩放。
- **大纲导航**：侧栏（`Cmd/Ctrl+Shift+O`）按标题高亮当前阅读章节。
- **标准打印**：`Cmd/Ctrl+P` 随时调起系统打印，去除干扰元素，极致优化墨水耗用。

---

## 就地编辑（F2）

- **基础核心功能，永久免费**，无任何使用配额或付费拦截。
- 直接在阅读画布当前光标处无缝开启编辑，保留完整视觉上下文。
- 适合快速修正错别字、补充段落或微调格式。完成后按 `Esc` 或再按 `F2` 即可无缝回到渲染阅读视图。
- 使用 `Cmd/Ctrl+S` 保存，严格保留原始字节与换行格式。

---

## 分屏视图（F3）

- 左侧 Markdown 源码编辑器，右侧毫秒级渲染预览。
- 编辑输入自动实时触发预览更新（内置智能防抖，输入流畅无卡顿）。
- 滚动窗格双向联动；**活动光标所在行在预览端高亮对齐**。
- **试用政策**：内置 300 次开箱试用体验。**额度用尽后绝不锁死**，用户仍可正常使用分屏预览功能（仅在切换新文件时弹出温和的 Pro 购买引导提示），**文件编辑与保存能力永不拦截**。

---

## 工作区与高级导出（Pro 特性）

- **工作区文件夹抽屉**（`Cmd/Ctrl+Shift+W`）：树状浏览并管理本地整个项目目录中的 Markdown 文件。
- **高级多渠道导出**：直接 PDF 导出（`Cmd/Ctrl+Shift+P`）、2x Retina 高清长图导出（`Cmd/Ctrl+Shift+E`）、单文件独立 HTML 导出（`Cmd/Ctrl+Shift+H`）。
- 社区版内置 300 次免费体验配额；终身买断用户永久无限制。

---

## 保存与安全

- QvReader 保留文件的**原始字节**：严格检测换行符（LF/CRLF）与编码（UTF-8，含/不含 BOM），保存时原样保留。
- 若文件在外部被其他编辑器修改，覆盖保存前会自动弹出冲突提醒。
- 未保存修改时关闭窗口或切换模式，会提示保存、放弃或停留。无论是试用期满还是弹窗提示，**保存功能永远不会被锁定**，绝不丢失用户数据。

---

## 系统安装与信任指引

- **macOS**：首次打开若遇 Gatekeeper 拦截，请右键点击应用选择“打开”；或在终端执行 `xattr -cr /Applications/QvReader.app`。
- **Windows**：若遇 SmartScreen 蓝色拦截弹窗，请点击“更多信息”并选择“仍要运行”。
