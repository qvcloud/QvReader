# 用法与键盘快捷键

QvReader 围绕三种状态设计。你始终从**阅读模式**开始（默认状态，也是唯一安全的视图——
普通的点击与键入绝不会修改你的源文件）。

## 核心操作

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 打开文件 | 双击 `.md`，或 `qvreader file.md`，或 文件 → 打开 | 相同 |
| 将文件夹作为工作区打开 | `qvreader .` | 相同 |
| 进入**就地编辑**（永久免费基础功能） | `F2` | `F2` |
| 进入**分屏视图**（每日 20 次免费，超额软提示不限制） | `F3` | `F3` |
| 返回阅读 | `F3` / `F2`（切换） | 相同 |
| 保存 | `Cmd + S` | `Ctrl + S` |
| 标准打印（系统原生，永久免费） | `Cmd + P` | `Ctrl + P` |
| 导出为 PDF | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| 导出为长图（PNG） | `Cmd + Shift + E` | `Ctrl + Shift + E` |
| 导出为独立 HTML | `Cmd + Shift + H` | `Ctrl + Shift + H` |
| 切换大纲侧栏 | `Cmd + Shift + O` | `Ctrl + Shift + O` |
| 切换工作区侧栏 | `Cmd + Shift + W` | `Ctrl + Shift + W` |
| 快捷键速查 | `Cmd + /` | `Ctrl + /` |
| 缩放 | `Cmd + 滚轮` | `Ctrl + 滚轮` |
| 关闭 / 退出 | `Esc`（文档干净时） | `Esc` |
| 设置 | `Cmd + ,` | `Ctrl + ,` |

## 阅读模式

- 阅读、滚动、选中文本、点击链接、查看图片。
- **大纲**侧栏：按标题导航；当前章节高亮。
- **主题**与字号位于设置（`Cmd/Ctrl+,`）中。
- 标准系统打印（`Cmd/Ctrl+P`）随时可用，格式经过严格排版优化。

## 就地编辑（F2）

- **基础核心功能，永久免费**，无任何配额与弹窗拦截。
- 直接在阅读画布当前光标处编辑，保留上下文。
- 适合快速修正错别字、坏链接或做轻量修订，完成后按 `Esc` 或再按 `F2` 即可无缝回到渲染阅读。
- 使用 `Cmd/Ctrl+S` 保存，严格保留原始字节与换行格式。

## 分屏视图（F3）

- 左侧：Markdown 源码；右侧：实时渲染预览。
- 编辑自动更新预览（做了智能防抖，输入流畅无延迟）。
- 滚动的窗格带动另一侧；你的**活动行在预览端高亮**并保持对齐。
- **免费额度**：社区版用户每日拥有 20 次免费分屏使用额度（每日自动重置）。超额后，针对每个新文件仅弹出一次非阻塞的购买引导建议；用户关闭弹窗后，分屏编辑与实时预览**完全不受限制**，随时随心使用。

## 工作区与高级导出（Pro 特性）

- **工作区文件夹抽屉**（`Cmd/Ctrl+Shift+W`）：树状浏览并管理本地整个项目目录中的 Markdown 文件。
- **直接 PDF 导出**（`Cmd/Ctrl+Shift+P`）、**高清长图 PNG 导出**（`Cmd/Ctrl+Shift+E`）、**单文件独立 HTML 导出**（`Cmd/Ctrl+Shift+H`）。
- 社区版内置 **300 次免费体验配额**；终身买断用户永久无限制。

## 保存与安全

- QvReader 保留你文件的**原始字节**：检测换行（LF/CRLF）与编码（UTF-8，含/不含 BOM），
  写回时原样保留。
- 如果文件在 QvReader 之外被磁盘上的其他程序修改，覆盖前会提醒你。
- 存在未保存修改时关闭或切换模式，会询问保存、放弃或停留。无论是试用期满还是弹窗提醒，**保存功能永远不会被锁定**，绝不丢失用户数据。

## 语言

在 设置 → 通用 → 语言 中切换界面语言。支持：English、简体中文、
日本語、한국어、Português (Brasil)、Español。
