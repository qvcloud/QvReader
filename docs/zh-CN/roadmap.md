# 产品路线图

对 QvReader 正在规划、已完成里程碑以及刻意不做的设计边界，提供公开透明的视图。
只有经过严谨规格化、并被证明不损害启动速度、包体大小、Markdown 保真或核心阅读体验的功能，才会进入正式开发。

---

## 已达成里程碑（v0.1.0 ~ v0.1.4）

- [x] **极致性能与体积优化（v0.1.4）**：原生安装包约 5MB，JS 入口 614KB，100% WOFF2 数学字体，冷启动 <50ms，支撑 50,000+ 行大文档 60 FPS 流畅滚动。
- [x] **智能屏宽排版引擎（v0.1.3）**：响应式流式布局（896px~1280px），告别宽屏两侧过宽留白，支持“自适应 / 标准 / 全宽”3 种排版模式自由切换。
- [x] **Mermaid 图表全屏交互缩放（v0.1.3）**：支持流程图、时序图与架构图渲染，双击弹出全屏交互式缩放模态窗（拖拽平移、滚轮缩放与全屏检查）。
- [x] **全场景 4 种导出流水线（v0.1.3）**：系统原生墨水友好打印、高保真矢量 PDF、2x Retina 高清长图自动复制到剪贴板、离线便携单文件 HTML。
- [x] **极简核心交互契约（v0.1.0）**：双击 `.md` 毫秒级阅读、`Esc` 退出、`F2` 就地原位编辑、`F3` 实时分屏预览。
- [x] **原始字节保真与安全保存（v0.1.0）**：严格保留源文件 LF/CRLF 换行与 UTF-8 编码格式，外部修改冲突检测，未保存内容退出防护。
- [x] **多语言完整支持（v0.1.0 ~ v0.1.3）**：简体中文、English、日本語、한국어、Español、Português (Brasil) 6 国语言 100% 对齐。

---

## 近期规划候选（v0.1.5+）

- 🔄 **代码签名合规集成**：正式接入 Apple Developer ID 签名与苹果公证（彻底免除 Gatekeeper 弹窗），并接入 Windows SignPath 商业级开源代码签名证书。
- 🔄 **自动更新检测**：启动时对官方 Releases 进行轻量静默比对，在新版本发布时提供优雅的更新提示与更新日志展示。
- 🔄 **代码块阅读增强**：可选的代码行号显示、一键复制代码反馈动画以及特大代码块折叠。
- 🔄 **Linux 发行生态打磨**：完善 Linux 下的 Flatpak 与 Snap 官方打包通道。

## 明确排除的功能

项目宪章为守护“快速、小巧、专注”的定位，排除以下内容：

- 强制联网与云端内容同步（恪守 Local-First 原则，绝不采集文档内容）。
- 强制按月订阅制（坚持良性商业化，一次买断终身使用）。
- 博客发布、微信公众号排版或通用 CMS。
- 做成对标 VS Code、Obsidian 的重型知识库或笨重 IDE。
- 强制或静默修改操作系统默认文件关联。
- 扰人的广告、水军弹窗或在阅读界面增加视觉噪音的 Pro 徽章。

候选工作在 [GitHub Issue 追踪器](https://github.com/qvcloud/QvReader/issues) 中公开讨论。
