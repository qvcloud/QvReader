# 功能特性

对 QvReader 今天能做什么、以及刻意不做什么，做出简洁而诚实的说明。

## 产品定位

QvReader 是一款**轻量、快速、以文档为先的 Markdown 阅读器**，附带恰到好处的编辑能力。
它瞄准"快速读一个 README / AI 生成的文档 / 本地笔记"的场景——打开它，像网页一样阅读，
需要时就地修改，按 `Esc` 关闭。它**不是** IDE、知识库、云同步资料库或完整 CMS。

核心价值（摘自项目宪章）：

1. 打开快、安装小。
2. 干净的阅读界面，无杂乱。
3. 阅读是默认；编辑是显式的，因此你不会误改源码。
4. 编辑足以完成真正的修改，但绝不做成笨重的编辑器。
5. 本地文件、本地优先，无需账号或云端。

## 当前能力（v0.1.0）

- **即时阅读** CommonMark / GFM 文档。
- **保真** —— 源文件是唯一事实来源。未知语法、换行、编码均原样保留。
- **F2 就地编辑**与 **F3 分屏编辑**，带实时预览。
- **代码高亮**（highlight.js）、**数学公式**（KaTeX）。
- **目录大纲**、**文件夹工作区**与文件树。
- **主题**、可调字号、**6 种界面语言**。
- **CLI**（`qvreader <文件>` / `qvreader .`）。

## 明确排除的功能

项目宪章为守护"快速、小巧、专注"的定位，排除以下内容：

- 云同步、Git 托管同步或内置网盘。
- 博客发布、微信公众号排版或通用 CMS。
- 做成对标 Typora、Obsidian 或 VS Code 的知识库 / IDE。
- 账号、支付、激活码、订阅或多设备授权。
- 强制或静默设置默认文件关联。
- 庞大而未经验证的插件与主题生态。
