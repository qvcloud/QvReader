# 功能特性

对 QvReader 今天能做什么、以及刻意不做什么，做出简洁而诚实的说明。

## 产品定位

QvReader 是一款**超轻量、快速、以文档为先的 Markdown 阅读器**，附带恰到好处的编辑能力。
它瞄准“快速读一个 README / AI 生成的代码文档 / 本地规范笔记”的高频场景——打开它，像网页一样阅读，需要时就地修改，按 `Esc` 快速关闭。它**不是** IDE、知识库、云同步资料库或重型 CMS。

核心价值（摘自项目宪章）：

1. 打开快、安装包极小（~5MB，冷启动 <50ms）。
2. 干净专注的阅读界面，无干扰、无广告。
3. 阅读是默认状态；编辑是显式操作，绝不误改源码。
4. 编辑足以完成日常修改，但绝不做成笨重沉缓的编辑器。
5. 本地文件、本地优先，无需账号或云端，100% 保护隐私。

## 功能版本与能力矩阵

### 社区免费版（Community Edition - 永久免费）

- **即时极速阅读**：CommonMark / GFM 完整排版，冷启动 <50ms，内存占用极低。轻松承载 50,000+ 行超长文档以 60 FPS 流畅滚动。
- **智能屏宽排版**：响应式流式布局（896px~1280px），告别宽屏两侧过宽留白，可在设置中自由切换“自适应 / 标准 / 全宽”3 种排版模式。
- **原始字节保真**：源文件是唯一事实来源。未知语法、换行符（LF/CRLF）与编码格式（UTF-8/BOM）原样保留。
- **F2 就地编辑（核心基础功能，永久免费）**：基于 CodeMirror 6，无缝进入阅读画布原位编辑，无任何使用次数与弹窗限制。
- **F3 实时双栏分屏**：左侧源码，右侧毫秒级实时渲染预览。内置 300 次开箱试用体验；**额度用尽后绝不锁死**，用户仍可继续无障碍使用（仅在切换新文件时弹出温和的 Pro 购买提示），**文件的编辑与保存能力永不拦截**。
- **工程图表与公式**：Mermaid 原生图表渲染与 KaTeX 块级/行内数学公式渲染。支持**双击 Mermaid 图表进入全屏交互式缩放弹窗**（支持拖拽、平移、放大缩放与全屏检查）。
- **阅读导航与交互**：右键快捷菜单、文档目录大纲（TOC）、预置主题切换与字号缩放。
- **原生系统打印**：`Cmd/Ctrl+P` 一键调起操作系统标准打印，专享墨水友好与无遮挡排版。
- **跨平台 CLI**：支持终端直接启动（`qvreader <文件>` / `qvreader .`）。
- **完全国际化**：内置 6 种宪法支持语言（简体中文、English、日本語、한국어、Español、Português (Brasil)）。

### Pro 专业版（Pro Edition - $9.99 终身买断）

- **充分免费体验**：社区版内置 300 次 Pro 功能体验配额，无需购买即可在自有文件上充分验证。
- **工作区管理**：文件夹抽屉与目录树（`Cmd/Ctrl+Shift+W`），一键在多文档工程间无缝穿梭。
- **全能导出闭环**：
  - **直接 PDF 导出**（`Cmd/Ctrl+Shift+P`）：带格式引导的高保真矢量 PDF 输出。
  - **高清长图 PNG 导出**（`Cmd/Ctrl+Shift+E`）：2x Retina 像素级无损排版截图，自动下载并同步复制到剪贴板。
  - **独立 HTML 导出**（`Cmd/Ctrl+Shift+H`）：内联离线样式与渲染引擎，单文件随处便携分发。
- **100% 离线激活与本地优先**：一次买断终身有效，支持 ≥3 台个人设备，本地签名校验无需常驻联网，彻底去除所有 Pro 提示。

## 明确排除的功能

项目宪章为守护“快速、小巧、专注”的定位，排除以下内容：

- 强制联网与云端内容同步（恪守 Local-First 原则，绝不采集文档内容）。
- 强制按月订阅制（坚持良性商业化，一次买断终身使用）。
- 博客发布、微信公众号排版或通用 CMS。
- 做成对标 VS Code、Obsidian 的重型知识库或笨重 IDE。
- 强制或静默修改操作系统默认文件关联。
- 扰人的广告、水军弹窗或在阅读界面增加视觉噪音的 Pro 徽章。
